# Studio Borges — Landing Page de Alta Conversão

> Landing page desenvolvida para o **Studio Borges (Amanda Borges)**, estúdio especializado em extensão de cílios e design de sobrancelhas em Osasco - SP.

---

## 👑 Sobre o Projeto

Este projeto foi construído para transformar o catálogo de serviços em uma experiência digital elegante, rápida e focada em conversão direta para o WhatsApp.

### 🌟 Destaques e Funcionalidades

- **Identidade Visual**: Paleta nobre em **Roxo Veludo Imperial** (`#0F0814`, `#180E21`) com detalhes em **Dourado Champagne Metálico** (`#DFB15B`).
- **Catálogo Interativo de Cílios**: Apresentação dos 6 volumes (Brasileiro, Egípcio, Híbrido, Russo, Fox Eyes e Power) com fotos reais, filtros e preços.
- **Harmonização de Sobrancelhas**: Design personalizado, aplicação de henna e protocolo de recuperação.
- **Simulador de Manutenção**: Calculadora dinâmica em tempo real onde a cliente escolhe a técnica e os dias desde a aplicação para ver o valor exato.
- **Benefício de 5% OFF**: Destaque para pagamentos via Pix ou dinheiro em espécie.
- **Políticas Claras**: Regras de tolerância, garantia de 7 dias, sinal de reserva e cuidados pré e pós-procedimento.
- **Localização e Estacionamento**: Endereço na Rua Ulisses Soares (Osasco), facilidade para estacionar e botão para traçar rota no Google Maps.
- **Conversão Otimizada**: Botão flutuante para computador e barra fixa inferior no celular para agendamento direto pelo WhatsApp com mensagens pré-formatadas.

## 💻 Como Rodar o Projeto Localmente

1. **Instale as dependências:**
   ```bash
   pnpm install
   # ou npm install
   ```

2. **Inicie o servidor de desenvolvimento:**
   ```bash
   pnpm dev
   # ou npm run dev
   ```

3. **Abra no navegador:**
   Acesse `http://localhost:3000`

4. **Gerar versão de produção (Build):**
   ```bash
   pnpm build
   # ou npm run build
   ```
